#### Introduction
# nxf-starsolo

This tool is a nextflow wrapper for batch STARsolo tasks.

#### Software Architecture
It is mainly used for `nextflow run` commands.
Currently it does not support pulling from gitee repositories, so it needs to be synchronized with github repositories.


#### installation tutorial
`nextflow run billsfriend/nxf-starsolo`
